## 现有功能基线（从代码梳理，改动时不得破坏）

### 用户系统

- 默认管理员 `admin`（首启自动初始化），多用户注册可在后台开关
- 登录签发 JWT（header `x-api-token`）；登录/注册支持 Google reCAPTCHA（后台配置）
- 个人资料：用户名/昵称/头像/标语/封面/邮箱；可改密码
- 站点级配置寄生在用户行上：站点标题、favicon、备案号、自定义 CSS/JS、S3 参数

### Memo（核心）

- Markdown 编写（markdown-it + shiki 高亮），支持 emoji 选择
- 可见性 `showType`：公开 / 仅自己（登录后可见）；游客另受"未来发布时间不可见"限制
- 可自定义发布时间、置顶（`pinned`）、显示定位
- 图片/视频上传（服务器或 S3，详见下），图片有缩略图与 `imgConfigs` 展示配置
- 外部内容嵌入：网易云音乐、B 站/YouTube 视频、外链卡片（自动抓 favicon+标题）、豆瓣读书/电影
- 点赞（`favCount`）、评论（可后台关闭，可配正序/逆序，评论支持回复和邮件提醒）
- 编辑 / 删除（仅作者本人）

### 标签（本次需求改造对象）

- 扁平一级标签：编辑时从已有标签联想选择，浏览页按标签筛选（AND）
- 无层级、无管理后台、无计数；存储与筛选约束见 `docs/DATA_MODEL.md`「标签存储」

### 文件上传

- 服务器模式：SHA256 秒传检查、自动缩略图、无用文件清理（移入 `$UPLOAD_DIR/removed`）
- S3 模式：预签名 URL 直传，可配图片压缩后缀

### 其他

- 友情链接管理（增删查）
- RSS 订阅（`/rss`）
- 暗黑模式、移动端适配（MobileNav）
- 全局配置后台（`/sys/settings`）：评论开关/排序、注册开关、邮件、reCAPTCHA 等
- 版本变化自动备份数据库；历史数据迁移脚本（`migrate*.go`）

## 技术方案（已实现，2026-08-19）

- 存储：独立 `Tag`（parentId 树，任意层级）+ `MemoTag` 关联表；`Memo.tags` 老列双写兼容
- API：`tag/list` 返回树+计数（支持 `?username=` 免登录）；`memo/list` 的 `tag` 参数支持全路径，筛选含全部子孙，多标签 AND；Tag 表未命中回退老 `LIKE`
- 迁移：`backend/migrate_tags.go` 启动幂等迁移存量扁平标签
- 前端：MemoEdit 树形选择器（过滤/就地新建多级）；浏览页面包屑+子标签下钻；Memo 卡片层级渲染（`tagPaths` 优先）
- URL：标签浏览页用多段路径 `/tags/:user/父/子`（catch-all 路由逐段编码）；旧 `%2F` 形式由 `middleware/redirect.go` 301 重定向到多段形式（防 SEO 重复内容，query 透传）
- 约束：标签禁逗号、≤10 级、单段 ≤50 字符
